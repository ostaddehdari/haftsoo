# S03-W01 — ساختار Monorepo و مالکیت

مخزن از چهار ناحیهٔ مالکیت تشکیل شده است:

| مسیر | مسئولیت | Deployable |
|---|---|---|
| `apps/web` | تجربه وب SSR، RTL و BFF سبک | `haftsoo-web` |
| `apps/api` | API هسته و ماژول‌های دامنه | `haftsoo-api` |
| `services/chat` | مسیر بلادرنگ و حضور کاربر | `haftsoo-chat` |
| `packages/contracts` | قراردادهای مشترک و Versioning | کتابخانه داخلی |

فایل `CODEOWNERS` مالک اولیه را مشخص می‌کند. با اضافه‌شدن تیم، هر ناحیه حداقل یک مالک اصلی و یک جانشین خواهد داشت. مرز سرویس‌ها بر مبنای دامنه است و انتقال کد فقط با ADR انجام می‌شود.
