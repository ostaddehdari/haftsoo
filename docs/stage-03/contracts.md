# S03-W05 — قراردادها و انواع مشترک

پکیج `@haftsoo/contracts` تنها منبع انواع عبوری بین Web، API و Chat است. نسخه فعلی قراردادهای Health، Envelope و پیش‌نویس پیام را تعریف می‌کند.

قواعد:

1. تغییر ناسازگار فقط با نسخه جدید API یا Major Package مجاز است.
2. Entity دیتابیس وارد قرارداد عمومی نمی‌شود.
3. تاریخ به ISO-8601 و شناسه به رشته منتقل می‌شود.
4. Contract Test قبل از انتشار اجرا می‌شود.
