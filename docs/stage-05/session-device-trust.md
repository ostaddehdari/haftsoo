# Session، Token و Device Trust — S05-W03

نشست مرورگر بر Cookie امن، HttpOnly، SameSite=Lax و CSRF امضاشده بنا می‌شود. Access token حداکثر ۱۰ دقیقه عمر دارد؛ Refresh token یک‌بارمصرف، Hash‌شده و دارای تشخیص استفاده مجدد است.

امتیاز ریسک دستگاه از ناشناخته بودن دستگاه، نبود Attestation، شکست‌های اخیر و جابه‌جایی غیرممکن IP ساخته می‌شود:

- کمتر از ۳۵: اجازه؛
- ۳۵ تا ۶۹: Step-up؛
- ۷۰ و بیشتر: رد درخواست.

کاربر باید نشست‌های فعال را ببیند و از راه دور لغو کند. منطق امتیازدهی این استیج قطعی و تست‌شده است؛ صدور OTP، Refresh token پایدار و صفحه نشست‌ها در `S18` تکمیل می‌شود.

سیاست ماشین‌خوان: `security/session-policy.json`.
