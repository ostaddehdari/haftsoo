# گیت خروج استیج ۱۸

- هر ۱۰ کار WBS دارای evidence و قرارداد اجرایی است.
- OTP و شمارهٔ خام ذخیره نمی‌شوند و RLS اجباری است.
- شمارش تلاش و reuse revocation از rollback خطا جان سالم می‌برند.
- Access/Refresh rotation، فهرست و ابطال نشست تست شده‌اند.
- Nuxt، نسخهٔ نصب‌شونده، Compose، secrets، migration و CI هم‌زمان اعتبارسنجی می‌شوند.
