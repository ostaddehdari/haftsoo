# S09-W04 — اعتبارسنجی و Repair هندسه

اعتبارسنجی برنامه بسته‌بودن حلقه، حداقل چهار نقطه، محدودهٔ WGS84 و حدود ایران را کنترل می‌کند. trigger پایگاه‌داده با `ST_Force2D`، `ST_MakeValid`، `ST_CollectionExtract` و `ST_Multi` هندسه را نرمال می‌کند و نتیجهٔ repair را در metadata ثبت می‌کند. هندسهٔ خالی یا نامعتبر رد می‌شود.
