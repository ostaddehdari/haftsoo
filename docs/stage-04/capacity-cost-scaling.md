# S04-W09 — ظرفیت، هزینه و Scaling

مدل قابل تکرار در `ops/capacity/model.json` قرار دارد و `capacity-plan.mjs` برآورد پایه را تولید می‌کند. این رقم Quote تأمین‌کننده نیست؛ برای مقایسه سناریو و کشف تغییرات غیرعادی است.

Scaling افقی Web/API/Chat بر CPU و P95، Kafka consumer بر Lag و Storage بر ظرفیت مصرفی انجام می‌شود. Database قبل از Scale-up با Index، Query plan و Pool بررسی می‌شود. آستانه‌های پایه: CPU برابر ۶۵٪، API P95 برابر ۴۰۰ms، Lag برابر ۳۰s و Storage برابر ۷۰٪.

بازبینی ماهانه شامل MAU، RPS اوج، تعداد آگهی فعال، حجم رسانه، پیام روزانه، هزینه هر آگهی فعال و هزینه هر MAU است. هر افزایش بیش از ۲۰٪ بدون رشد متناظر محصول نیازمند تحلیل است.
