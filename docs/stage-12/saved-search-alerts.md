# S12-W08 — جست‌وجوی ذخیره‌شده و Alert

Query نرمال‌شده با Hash یکتا برای هر کاربر ذخیره می‌شود. Endpointهای Saved Search فقط از BFF احرازشده و با امضای Service قابل فراخوانی‌اند؛ شناسه کاربر از Session معتبر BFF عبور می‌کند. Alert فوری، روزانه یا هفتگی است؛ Delivery با `idempotency_key` از اعلان تکراری جلوگیری می‌کند و کانال‌های Push، پیامک، ایمیل و داخل برنامه را پشتیبانی می‌کند. RLS دسترسی میان Tenantها را می‌بندد.
