# S02-W09 — Prototype صفحات بحرانی

Prototype استاتیک در `deploy/web` پیاده شده و بدون سرویس خارجی اجرا می‌شود.

سناریوهای قابل آزمون:

1. خانه ← انتخاب شهر ← جست‌وجو.
2. فهرست آگهی ← فیلتر ← باز کردن کارت.
3. جزئیات آگهی ← نشان‌کردن ← نمایش تماس آزمایشی.
4. حساب کاربر و وضعیت آگهی‌ها.
5. صفحه سیستم طراحی، Theme روشن/تیره و حالت Reduced Motion سیستم.

این نمونه قرارداد بصری و تعاملی است، نه معماری نهایی Nuxt. داده‌ها ساختگی‌اند و هیچ شماره یا دارایی واقعی سرویس دیگر در آن وجود ندارد.
