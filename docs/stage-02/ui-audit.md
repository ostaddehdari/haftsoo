# S02-W01 — ممیزی رابط کاربری

نسخه: ۱.۰ — دامنه: وب دسکتاپ، موبایل و PWA

این ممیزی الگوهای یک بازار آگهی را به قابلیت‌های مستقل هفت‌سو تبدیل می‌کند؛ هویت، نام و دارایی‌های محصول دیگر کپی نمی‌شوند.

| خانواده | صفحه‌های اصلی | حالت‌های اجباری | ریسک کلیدی |
|---|---|---|---|
| کشف | خانه، انتخاب شهر، دسته‌بندی | پیش‌فرض، جست‌وجو، آفلاین | شروع بدون شهر |
| جست‌وجو | فهرست، نقشه، فیلتر | بارگذاری، نتیجه، خالی، خطا | همگام‌سازی URL و فرم |
| آگهی | جزئیات، گالری، تماس، گزارش | فعال، حذف‌شده، منقضی، تماس آشکار | حریم شماره و ضدتقلب |
| ثبت | دسته، فرم پویا، رسانه، پیش‌نمایش | پیش‌نویس، خطا، موفق، رد | از دست رفتن داده |
| هویت | موبایل، OTP، نشست‌ها | ارسال، انتظار، تلاش مجدد، مسدود | نرخ درخواست و امنیت |
| ارتباط | فهرست گفتگو، گفتگو | خالی، ارسال، آفلاین، مسدود | تحویل و ترتیب پیام |
| حساب | آگهی‌ها، نشان‌ها، کیف‌پول، تنظیمات | مهمان، عضو، خالی، خطا | مجوز و بازیابی |
| اعتماد | ایمنی، گزارش، پشتیبانی | مقاله، فرم، نتیجه | مسیر رسیدگی روشن |

## یافته‌های مشترک

- RTL در سطح سند است و اعداد، تلفن و قیمت در جزیره‌های `dir=ltr` کنترل می‌شوند.
- Header دسکتاپ در موبایل به Header فشرده و Bottom Navigation تبدیل می‌شود.
- Modal در نمایشگر کوچک Bottom Sheet یا تمام‌صفحه می‌شود؛ داده و URL نباید با تغییر اندازه از دست برود.
- تمام درخواست‌ها باید چهار حالت loading/empty/error/ready داشته باشند.
- فیلترها server-driven هستند اما کنترل‌های پایه باید مستقل از payload باقی بمانند.
- عمل‌های حساس (تماس، پرداخت، خروج، حذف) نیازمند ثبت رخداد و بازخورد صریح‌اند.

## خروجی

مسیرها و حالت‌ها در `design-system/route-manifest.json` و کنترل‌های مشترک در `design-system/component-manifest.json` منبع حقیقت‌اند.
