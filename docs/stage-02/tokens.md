# S02-W03 — توکن‌های طراحی

منابع: `design-system/tokens.json` و `design-system/tokens.css`.

- رنگ‌ها در چهار نقش brand، neutral، semantic و theme تعریف شده‌اند.
- کامپوننت حق استفاده مستقیم از Hex را ندارد و باید از توکن معنایی مصرف کند.
- فاصله‌ها بر شبکه ۴px، شعاع‌ها در پنج سطح و سایه‌ها در سه سطح‌اند.
- Theme روشن/تیره با `data-theme` و ترجیح سیستم سازگار است.
- لایه‌ها از base تا toast شماره‌گذاری شده‌اند تا رقابت z-index حذف شود.

تغییر توکن breaking با افزایش major نسخه Design System انجام می‌شود. افزوده شدن توکن سازگار minor و اصلاح مقدار patch است.
