# S02-W06 — Responsive

| نام | حداقل عرض | رفتار |
|---|---:|---|
| mobile | ۰ | یک ستون، Bottom Nav، Sheet تمام‌عرض |
| tablet | ۵۲۰px | Modal محدود، Grid دو ستون |
| desktop | ۷۶۸px | Header کامل، Sidebar فیلتر، Grid دو/سه ستون |
| wide | ۱۲۰۰px | Container حداکثر ۱۲۸۰px، Grid سه ستون |

- طراحی mobile-first است و Breakpoint بر اساس نیاز محتواست، نه مدل دستگاه.
- Tap target حداقل ۴۴×۴۴px و فاصله لبه موبایل ۱۶px است.
- در Listing، Sidebar از ۹۶۰px نمایش داده می‌شود؛ زیر آن فیلتر داخل Overlay است.
- تصویر کارت aspect-ratio ثابت دارد و متن عنوان حداکثر دو خط است.
- تغییر viewport نباید فرم ثبت آگهی، انتخاب محله یا Scroll گفتگو را reset کند.
