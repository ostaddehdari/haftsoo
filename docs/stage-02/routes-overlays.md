# S02-W02 — Route، Modal و Bottom Sheet

منبع ماشینی: `design-system/route-manifest.json`.

قرارداد مسیریابی:

- Base path محیط فعلی `/haftsoo` است؛ Router در محصول نهایی آن را از متغیر محیطی می‌گیرد.
- شهر، دسته، فیلتر قابل‌اشتراک و صفحه در URL ذخیره می‌شوند؛ وضعیت گذرای UI در URL قرار نمی‌گیرد.
- Route محافظت‌شده کاربر را پس از ورود به مقصد اولیه بازمی‌گرداند.
- صفحه حذف‌شده یا منقضی پاسخ معنایی مستقل دارد و به صفحه عمومی تغییر مسیر پنهانی نمی‌دهد.

قرارداد Overlay:

1. فقط یک Modal مسدودکننده هم‌زمان باز است.
2. Focus داخل Dialog محصور و بعد از بستن به Trigger بازگردانده می‌شود.
3. Escape و دکمه بستن رفتار یکسان دارند؛ کلیک backdrop برای عملیات مخرب غیرفعال است.
4. در عرض کمتر از ۵۲۰px، Pickerها Bottom Sheet و فرم‌های طولانی تمام‌صفحه‌اند.
5. Back مرورگر ابتدا Overlay را می‌بندد و سپس Route را تغییر می‌دهد.

Prototype، مسیرهای `#/home`، `#/search`، `#/post`، `#/account` و `#/system` و Overlay انتخاب شهر/فیلتر را پوشش می‌دهد.
