# ADR-0001: پشته فنی و مسیر تکامل معماری

- وضعیت: accepted
- تاریخ: ۱۴۰۵-۰۸-۰۷

## زمینه

هفت‌سو به SSR و SEO، API دامنه‌محور، پردازش مکانی، جست‌وجوی حجیم و چت بلادرنگ نیاز دارد. تیم باید بتواند MVP را بدون هزینه عملیاتی Microserviceهای زودهنگام تحویل دهد.

## تصمیم

- Nuxt 3 برای وب عمومی و پنل‌ها.
- NestJS برای API هسته و Workerهای دامنه.
- Go برای Chat و WebSocket.
- PostgreSQL/PostGIS منبع حقیقت تراکنشی و مکانی.
- OpenSearch برای Discovery، Redis برای Cache/Coordination و Kafka برای Eventها.
- هسته ابتدا Modular Monolith با Boundary و Contract روشن است؛ استخراج سرویس فقط با نیاز مقیاس، مالکیت یا ایزولاسیون انجام می‌شود.

## پیامدها

- سرعت بیشتر در MVP و تراکنش‌های ساده‌تر.
- الزام جدی به رعایت مرز ماژول‌ها و Outbox.
- عملیات مستقل Chat از ابتدا.
- نیاز به Contract Test برای API و Event پیش از استخراج سرویس‌ها.
