# بارگذاری مستقیم امضاشده

API پس از کنترل مالکیت، نوع، اندازه و سهمیه یک PUT امضاشدهٔ SigV4 ده‌دقیقه‌ای می‌دهد. Content-Type و SHA-256 داخل امضا bind می‌شوند؛ کلید محرمانه هرگز به مرورگر نمی‌رسد.

`S3_ENDPOINT` برای Worker داخلی و `S3_PUBLIC_ENDPOINT` برای URL مرورگر جدا هستند؛ دامنهٔ عمومی باید TLS و CORS محدود به Origin هفت‌سو داشته باشد.
