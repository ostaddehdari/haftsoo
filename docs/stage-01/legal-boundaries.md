# مرزهای حقوقی و فنی الگوبرداری

هفت‌سو می‌تواند از الگوهای عمومی بازارگاه‌های آگهی برای فهم جریان کار استفاده کند، اما محصول مستقل است.

## مجاز

- تحلیل رفتار عمومی رابط، Route، State و الگوی تعامل.
- طراحی مستقل قابلیت‌های هم‌رده با نام، کد و Asset هفت‌سو.
- استفاده از داده‌هایی که مجوز مناسب، منبع عمومی مجاز یا مالکیت هفت‌سو دارند.
- پیاده‌سازی مستقل API و Schema بر اساس نیاز کسب‌وکار.

## غیرمجاز

- کپی کد، Bundle، فونت دارای محدودیت، تصویر، آیکون یا متن دارای حق نشر.
- استفاده از نام، نشان، رنگ‌بندی یا Trade Dress گمراه‌کننده رقیب.
- ذخیره Token، Cookie، شماره تماس یا داده شخصی کاربران رقیب.
- دور زدن کنترل دسترسی، Rate Limit، CAPTCHA یا شرایط سرویس.
- وابستگی تولید به Endpoint خصوصی یا ناپایدار شخص ثالث بدون مجوز.

## کنترل انتشار

پیش از عرضه عمومی، Legal و Product باید نام، لوگو، متن‌ها، Assetها، Terms، Privacy Policy و منشأ داده‌های واردشده را بازبینی و ثبت کنند.
