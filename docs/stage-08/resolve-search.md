# S08-W07 — جست‌وجو و Reverse Resolve

جست‌وجو حداقل ۲ و حداکثر ۸۰ نویسه و سقف ۵۰ نتیجه دارد. تطبیق نام و Alias با Trigram رتبه‌بندی می‌شود. Reverse Resolve فقط نقاط در محدوده ایران را می‌پذیرد، bbox را پیش‌فیلتر می‌کند و `ST_Covers` را به‌کار می‌برد تا نقاط روی مرز نیز پوشش داده شوند.

Budget درخواست عمومی ۵۰۰ میلی‌ثانیه است. ترتیب `depth DESC, area ASC` نزدیک‌ترین واحد مکانی را جلوتر از والدهای وسیع قرار می‌دهد.
