# S10-W10 — گیت تأیید بصری صفحه نخست

استیج ۱۰ زمانی بسته است که:

- SSR، RTL، base path و Layout عمومی build شوند.
- Header، منوی موبایل، Multi-city و جست‌وجوی شهر با صفحه‌کلید کار کنند.
- صفحه نخست، دسته‌ها، شهرهای پربازدید، فوتر و نشان‌های اعتماد در موبایل و دسکتاپ سالم باشند.
- Light/Dark، reduced-motion و Loading/Error/Empty State آزمون شوند.
- canonical، JSON-LD، رویدادهای Analytics و احترام به GPC تأیید شوند.
- نسخه Nuxt و `deploy/web` هم‌تراز، تست‌ها سبز و Secret Review بدون مورد بحرانی باشند.
