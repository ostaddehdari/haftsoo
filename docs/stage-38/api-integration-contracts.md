# قراردادهای API و Integration

قراردادهای API با ورودی نامعتبر fail-closed، Tenant Isolation و پاسخ نسخه‌دار بررسی می‌شوند. تست Integration برای پایگاه‌داده، Search، Map، Chat، Media و Providerها باید بدون داده جعلی موفقیت گزارش کند؛ نبود وابستگی به‌صورت unavailable ثبت می‌شود.

Migration شماره ۲۹ اجرای تست، نتیجه، یافته دسترس‌پذیری، Snapshot و Release Gate را قابل ممیزی می‌کند.
