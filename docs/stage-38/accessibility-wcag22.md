# دسترس‌پذیری WCAG 2.2 AA

هدف رسمی WCAG 2.2 AA است. Critical و Serious، شکست Keyboard، Focus Trap، نام قابل‌دسترسی ناقص و Smoke ناموفق Screen Reader انتشار را متوقف می‌کنند. Skip Link، ترتیب Focus، RTL، کنتراست، Reduced Motion و وضعیت‌های خطا در مسیرهای اصلی کنترل می‌شوند.

یافته‌ها با Route، Browser، Rule ID و Selector Hash ذخیره می‌شوند تا PII وارد گزارش نشود.
