# راهبرد کیفیت و دروازه انتشار

هر Revision پیش از انتشار باید Unit، Integration، E2E، ماتریس مرورگر، WCAG و Visual Regression را بگذراند. تصمیم پیش‌فرض `block` است؛ نقص Critical/High یا قرنطینه‌شدن یک سفر حیاتی انتشار را متوقف می‌کند و مدرک تصمیم به‌صورت append-only ثبت می‌شود.

مالک هر شکست مشخص است، محیط تست از تولید جداست و Override بدون شاهد و تفکیک وظایف مجاز نیست.
