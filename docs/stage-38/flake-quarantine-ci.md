# Flaky Test، قرنطینه و CI

Flake فقط وقتی ثبت می‌شود که همان Revision در سه تلاش نتیجه متفاوت داشته باشد. قرنطینه مالک، Ticket و مهلت حداکثر هفت روز می‌خواهد و برای سفرهای حیاتی ممنوع است.

CI Trace، Screenshot، گزارش HTML و نتیجه هر Browser را نگه می‌دارد؛ Retry باعث سبز کاذب Release Gate نمی‌شود.
