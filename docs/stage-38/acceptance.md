# پذیرش استیج ۳۸

استیج ۳۸ با دقیقاً ۱۰ ورک تکمیل است: راهبرد QA، سفرهای حیاتی، قرارداد API/Integration، WCAG 2.2 AA، سه مرورگر Desktop، دو مرورگر Mobile، Visual Regression، فارسی/RTL، کنترل Flaky و پنل داخلی QA.

Playwright، ماتریس ماشین‌خوان، Release Gate پیش‌فرض مسدود، Migration برگشت‌پذیر، RLS، CI و تست Regression هدر/فیلترها الزامی‌اند. این استیج کنترل جدیدی به هدر عمومی اضافه نمی‌کند.
