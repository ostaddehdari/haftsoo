# سفرهای حیاتی کاربر

پنج سفر Search/Filter، Map/List، OTP/Session، Submission/Draft و Post/Contact/Chat در `quality/journeys.json` نسخه‌بندی شده‌اند. هر سفر باید از ورودی عمومی تا نتیجه قابل مشاهده تست شود و وضعیت URL، حریم خصوصی و Idempotency را حفظ کند.

فیلترهای دسته، قیمت، عکس‌دار و فوری در Desktop و Mobile جزو Gate هستند و حذف یا بی‌اثرشدن آن‌ها Regression مسدودکننده است.
