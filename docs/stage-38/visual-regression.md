# رگرسیون بصری

سطوح Home، Listing Desktop و Listing Mobile با Selectorهای نسخه‌بندی‌شده سنجیده می‌شوند. تغییر بیش از ۲۰ واحد basis point یا Component تغییرکرده بدون تأیید، Gate را می‌بندد.

Baseline فقط روی `main` و با تأیید چهارچشمی به‌روزرسانی می‌شود؛ Snapshot شکست ۳۰ روز نگه‌داری و با SHA-256 شناسایی می‌شود.
