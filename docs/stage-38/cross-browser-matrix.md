# ماتریس مرورگر

Desktop روی Chromium، Firefox و WebKit و Mobile روی Mobile Chrome و Mobile Safari اجرا می‌شود. نبود هر مرورگر لازم یا شکست حتی یک تست Gate را مسدود می‌کند.

ماتریس دقیق در `quality/browser-matrix.json` است و Playwright پروژه‌های مستقل با Trace و Screenshot فقط هنگام شکست تولید می‌کند.
