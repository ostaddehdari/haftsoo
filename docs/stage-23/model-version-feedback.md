# S23-W08 — نسخه مدل، بازخورد و ممیزی

مدل‌های متن، تصویر، تکرار و Ensemble با وضعیت Shadow/Active/Retired نسخه‌بندی می‌شوند. تصمیم انسانی به‌صورت True Positive، False Positive، False Negative یا Duplicate Confirmed به Feedback امن تبدیل می‌شود. فعال‌سازی نسخه جدید نیازمند گزارش Drift و دروازه کیفیت است.
