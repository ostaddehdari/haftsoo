# S07-W02 — چرخهٔ انتشار کاتالوگ

هر Import یک Release تغییرناپذیر با نسخه افزایشی و SHA-256 می‌سازد. حالت‌ها `draft → published → retired` هستند. در هر Tenant فقط یک Release منتشرشده مجاز است.

انتشار در تراکنش Serializable انجام می‌شود: نسخه قبلی Retire و نسخه Draft جدید Published می‌شود. Rollback محتوایی با انتشار دوبارهٔ یک نسخه بازسازی‌شده انجام می‌گیرد؛ دادهٔ تاریخی و Manifest حذف نمی‌شوند.
