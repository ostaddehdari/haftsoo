# S07-W01 — مدل دامنهٔ فهرست موضوعی

هر دسته با `external_key` پایدار، `slug` قابل نمایش، عنوان فارسی، والد اختیاری، ترتیب و عمق نگهداری می‌شود. درخت حداکثر ۸ سطح دارد و Trigger دیتابیس والدِ خارج از Tenant/Release و چرخه را رد می‌کند.

شناسه داخلی UUID است؛ `external_key` فقط کلید Import و اتصال به داده‌های مبدأ است. URLها از `slug` ساخته می‌شوند و تغییر عنوان، هویت دسته را تغییر نمی‌دهد.
