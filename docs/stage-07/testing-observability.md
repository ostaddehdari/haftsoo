# S07-W09 — آزمون، بودجه و مشاهده‌پذیری

تست‌های واحد، Checksum قطعی، ساخت درخت، Rule شرطی و رد Cycle/Missing field/Select ناقص را پوشش می‌دهند. `catalog-contract.mjs` وجود Schema، RLS، API و Fixture را کنترل می‌کند.

در عملیات، Release version و Checksum در پاسخ API و Import job ثبت می‌شوند. خطای اعتبارسنجی Path و Code پایدار دارد تا داشبورد مدیریت بتواند خطا را دقیق نمایش دهد. هدف Query عمومی همان بودجه Interactive استیج ۶ و Timeout برابر ۵۰۰ms است.
