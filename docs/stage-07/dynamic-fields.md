# S07-W03 — فیلدها و گزینه‌های پویا

انواع پشتیبانی‌شده: متن کوتاه/بلند، عدد صحیح/اعشاری، بولی، انتخاب تکی/چندتایی، تاریخ، موقعیت و رسانه. Validator و UI metadata به‌شکل JSONB نسخه‌شده‌اند.

فیلدهای Select الزاماً گزینه دارند. مقدار گزینه مستقل از عنوان فارسی است تا تغییر متن باعث شکستن Query و آگهی‌های موجود نشود. `filterable` و `searchable` قرارداد آیندهٔ Index است.
